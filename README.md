## 📖 Sobre

Este e-book gratuito apresenta curiosidades fascinantes sobre IA usando uma estética retrô de 16 bits. Todo o conteúdo é atualizado para **maio de 2026**, cobrindo os modelos mais recentes como GPT-5.5, Claude Opus 4.7 e Gemini 3.1 Pro.

## 🚀 Como Usar

### Ler no navegador
```bash
# Abra o arquivo no seu navegador
start index.html
```

### Exportar como PDF
1. Abra `index.html` no Chrome ou Edge
2. Pressione `Ctrl + P`
3. Selecione **"Salvar como PDF"**
4. ✅ Ative **"Gráficos de fundo"**
5. Margens: **Nenhuma**
6. Clique em **Salvar**

## 🛠️ Tecnologias

- **HTML5** — Estrutura semântica com tags `<article>` e `aria-labels`
- **CSS3** — Animações, temas por capítulo, `@media print` para PDF
- **JavaScript** — Geração dinâmica do sumário lateral
- **Google Fonts** — Press Start 2P + VT323 (fontes pixeladas)
