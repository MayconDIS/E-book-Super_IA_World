# Requisitos do Projeto

## Requisitos Funcionais (RF)
- [x] **RF01: Estética Retro** - O design deve refletir o estilo 16-bit de Super Mario World.
- [x] **RF02: Conteúdo Atualizado** - Informações técnicas sobre IA devem refletir o cenário de Maio/2026.
- [x] **RF03: Sumário Interativo** - Navegação rápida via "Mapa do Mundo" (Sidebar e Índice).
- [x] **RF04: Exportação PDF** - Versão estática otimizada para leitura offline.
- [ ] **RF05: LinkedIn Marketing** - Tutorial de promoção (implementado, aguardando validação final).
- [ ] **RF06: Deploy GitHub Pages** - Hospedagem da versão interativa.

## Requisitos Não Funcionais (RNF)
- [x] **RNF01: Performance** - Carregamento rápido de assets (pixel art leve).
- [x] **RNF02: Responsividade** - Ajuste básico para diferentes telas (foco em Desktop/Tablet).
- [x] **RNF03: SEO** - Meta tags para indexação e compartilhamento social.
- [x] **RNF04: Acessibilidade** - Uso de tags semânticas e ARIA labels.

## Critérios de Aceite (UAT)
- [ ] O sumário lateral deve recolher/expandir corretamente.
- [ ] O arquivo PDF gerado deve manter as cores originais (padrão Print).
- [ ] O tutorial do LinkedIn deve conter passos claros para viralização.
