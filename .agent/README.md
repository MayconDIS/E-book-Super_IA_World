# Memória do Agente (.agent)

Este diretório contém instruções e skills específicas para agentes de IA que trabalham neste repositório.

## Skills Disponíveis
- **GSD**: Metodologia de planejamento e execução.
- **Caveman**: Modo de comunicação ultra-comprimido para eficiência de tokens.

## Como usar
Sempre leia o conteúdo de `./.agent/skills/` ao iniciar uma nova sessão para garantir consistência no workflow e comunicação.
